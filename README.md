# VerdantSMP Staff

Optimized Paper 1.21.11 staff plugin for VerdantSMP.

## Features

- /vanish with staff-style toggle messages
- /sfmode
- /staffchat
- /freeze
- /mute
- /heal
- /feed
- /god
- /tp
- /tphere
- /inspect
- /fly
- /speed
- /kick
- /ban
- /warn
- /invsee
- /report
- /clearchat
- /staffmenu

## Build

```bash
mvn clean package
```

The generated jar will be in `target/`.

## Download

You can download the repository as a ZIP from GitHub, then build the jar locally with Maven.

## Notes

- No /staff command
- No rank system
- Paper 1.21.11 compatible
- Optimized to avoid unnecessary server lag
