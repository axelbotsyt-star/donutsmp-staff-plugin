# VerdantSMP Staff

Optimized Paper 1.21.11 staff plugin for VerdantSMP.

## Features

- /vanish
- /sfmode
- /staffchat
- /freeze
- /mute
- /heal
- /feed
- /god
- /tp
- /tphere
- /inspect
- /fly
- /speed
- /kick
- /ban
- /warn
- /invsee
- /report
- /clearchat
- /staffmenu
- GUI staff menu with cleaner layout

## Build

```bash
mvn clean package
```

The generated jar will be in `target/`.

## Download

Download the project source ZIP here:
https://github.com/axelbotsyt-star/donutsmp-staff-plugin/archive/refs/heads/main.zip

Then build the jar locally with Maven.
